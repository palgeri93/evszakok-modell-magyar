# Évszakok – térbeli modell

A `saisons.swf` magyar adaptációja. A HTML-oldal a mellékelt Ruffle JavaScript/WebAssembly lejátszóval futtatja a magyarított eredeti programot. Az eredeti animációk és számítások megmaradnak.

## Indítás

GitHub Pages: https://palgeri93.github.io/evszakok-modell-magyar/

Helyben az `inditas.cmd` indítja (Python 3), vagy `python -m http.server 8000`. Ezután http://localhost:8000/ . A HTML fájl közvetlen megnyitása helyett HTTP-kiszolgáló szükséges.

A Nagyítás gomb a rendelkezésre álló böngészőterülethez igazítja a megjelenítést. A magyar szövegek jegyzéke a `forditas.json` fájlban található.

## Forrás és jogok

Az eredeti szerzők és a programban található forrásjelölések megmaradtak. A magyar adaptáció nem hivatalos kiadás, az eredeti szerzői jogokat és engedélyeket nem módosítja. Az eredeti program felhasználási feltételei továbbra is érvényesek. Ruffle: MIT / Apache-2.0; licencek a `ruffle` mappában.
